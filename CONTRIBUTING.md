# Contributing

For installation and everyday use, start with the [README](README.md).

For code or documentation changes, see the [development guide](docs/DEVELOPMENT.md),
[architecture](docs/ARCHITECTURE.md) and [validation scope](docs/VALIDATION.md).
Project-wide coding-agent instructions live in [AGENTS.md](AGENTS.md); Claude and
Copilot entry files point to the same shared guidance.

Please keep changes focused and include the relevant checks in pull requests.
For UI changes, include screenshots at a normal and compact card size. For reported
bugs, include anonymized configuration and reproduction steps; do not publish
Home Assistant tokens, private dashboard exports or personal installation details.
