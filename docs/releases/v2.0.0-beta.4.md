# Vallox IV Card 2.0 — efficiency and heater history

Click the efficiency number or heater symbol to open that entity's Home Assistant
more-info dialog and history, just like the temperature readings.

- Works with pointer, touch, Enter and Space, with Finnish/English accessible labels
  and visible keyboard focus. Touch areas remain at least 44×44 px in compact cards.
- Uses the existing `efficiency` and `post_heater` configuration; no new YAML is needed.
- A calculated efficiency estimate has no separate entity history. The heater's
  history remains accessible even when its current state is unknown.
- Opens Home Assistant's own dialog; the available history and chart type depend on
  the selected entity and Recorder. Inspecting history does not send a device command.

In HACS, update repository information and select **v2.0.0-beta.4** under
**Redownload → Need a different version?**, then reload the frontend.
This is an opt-in prerelease; the stable release remains v1.0.0.

Validation: TypeScript, ESLint, production build, 35 logic tests, 50 browser tests
and 13 companion-template tests. Browser checks cover event targeting, keyboard
activation, compact touch areas and the existing airflow/layout regressions.

The optional companions and winter energy analysis retain their existing field-test
limitations. See [validation status](https://github.com/raunosr/vallox-iv-card/blob/v2.0.0-beta.4/docs/BETA-VALIDATION.md).
