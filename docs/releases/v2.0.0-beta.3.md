# Vallox IV Card 2.0 — clearer airflow and readings

The first beta's core and airflow were too subtle in some HA themes. This update makes
the ventilation state easier to read while keeping the integrated controls and energy row.

- A larger core with a stronger outline, using more of the space available in the card.
- Saturated temperature gradients, thicker moving segments and larger arrowheads.
- Larger, heavier temperature readings and clearer air-stream labels.
- Stronger selection borders and icons for the active profile; Boost and Fireplace use
  an amber accent, also shown in the header.
- Small secondary readings keep their values visible across fonts and languages; long labels shorten with the complete text available in a tooltip.
- The energy row keeps its existing size and missing-meter behavior.
- Core position, bypass routing, stopped supply flow and the frosted defrost effect remain
  consistent between operating states. Reduced motion and configured colours still work.

In HACS, update repository information and select **v2.0.0-beta.3** under
**Redownload → Need a different version?** Reload the frontend after installation.
Existing beta 1 YAML needs no changes. Beta 2 was stopped by CI before publication;
this is the next downloadable beta. This remains an opt-in prerelease; stable users
remain on v1.0.0.

Validation: TypeScript, ESLint, production build, 35 logic tests, 45 browser tests and
13 companion-template tests. Browser checks include compact layouts, light/dark and
blue-grey surfaces, selected-button contrast, arrow size and an unchanged energy row.

The optional HA companions still need real-device timer/restart validation. Winter
energy findings still need testing with working meters and actual defrost history.
See [validation and limitations](https://github.com/raunosr/vallox-iv-card/blob/v2.0.0-beta.3/docs/BETA-VALIDATION.md).
