# Vallox IV Card 2.0.1

Fixes theme compatibility when a dashboard uses transparent or glass cards.

- The card now lets Home Assistant render the background, border, radius and shadow.
  Its former background override could cover a theme's translucent glass layer.
- Removes the extra tinted surface overlay and respects theme border widths,
  including borderless cards. Normal profile controls use the theme's primary colour.
- Temperature colours, airflow animation and heater/boost indicators remain distinct.
  Gradient card backgrounds no longer remove the SVG strokes that separate air channels.
- Adds five browser regressions for theme inheritance and live theme changes.

## Update

Update **Vallox IV Card** to **v2.0.1** in HACS, then reload the dashboard on each
browser/tablet. If the version is not listed, use **⋮ → Update information** in HACS.
Existing card configuration works unchanged; no extra styling is required.

Type checking, linting, logic tests and browser checks cover this correction.
The optional seasonal/profile companions remain experimental. Energy findings
still require validation with working meters and real winter/defrost history.
