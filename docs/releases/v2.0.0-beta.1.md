# Vallox IV Card 2.0 — first public beta

An opt-in redesign of the Vallox dashboard card, with understandable airflow,
integrated profile controls and measured electricity. **This is a prerelease.**
The stable channel remains on v1.0.0.

## What changed

- A responsive light/dark design for HA Sections and masonry, including compact cards.
- A stationary heat-exchanger core with distinct recovery, bypass, cool-recovery and
  defrost states. Defrost uses a frosted edge and melting droplets; the ice effect is
  illustrative. Air routes remain separate and the heater stays on the supply path.
- CO₂/humidity beside extract air; core-outlet temperature and heater status beside
  supply air; a labelled fan icon beside the fan request percentage.
- Integrated Home/Away/Boost buttons, with optional Fireplace/Extra/Auto only when
  the selected unit reports support. Normal controls target the configured fan entity.
- Measured power, daily/24-hour energy, seven-day history and explainable local findings.
  Missing meters and insufficient history suppress energy conclusions.
- Finnish/English labels, visual configuration, keyboard controls and reduced motion.
- Explicit percent/ratio handling: 1% stays 1%. Unknown heater state stays unknown.

## Install with HACS

Open **Vallox IV Card → ⋮ → Update information**, then **Redownload → Need a different
version? → v2.0.0-beta.1**. Reload the frontend afterward. For future beta update
notifications, opt into the repository's prerelease switch in the HACS integration.
See [HACS version selection](https://hacs.xyz/docs/use/repositories/dashboard/#downloading-a-specific-version-of-a-repository)
and [prerelease switches](https://www.hacs.xyz/docs/use/entities/switch/).

The attached `vallox-iv-card.js` is the complete compiled card; no build step is needed.
The HACS resource is `/hacsfiles/vallox-iv-card/vallox-iv-card.js`. A separate `/local/`
copy will not change when HACS updates, and should not be loaded alongside this version.

## Migration

Save your existing card YAML and try the beta in a separate view. Existing entity
bindings and `custom:vallox-iv-card` remain supported. Add `fan_entity` for the integrated
buttons; old absolute label positions do not carry over to the redesigned layout.
The core-outlet binding must be the pre-heater sensor, not the final supply temperature.

## Experimental companions and known limits

Optional seasonal winter-lock and native profile-timer blueprints are included in
the source. **They are not installed or enabled by a HACS card update, and have not
completed real-device field validation.** Test timer expiry, repeat requests, manual
override and restart behavior before replacing existing automations. Seasonal Auto
starts disabled and needs sufficient outdoor-temperature history.

Energy findings require a working cumulative meter, adequate reporting cadence and
Recorder history. Winter energy/defrost behavior still needs broader field testing.
There is no automatic temperature or frost-setting adjustment, no universal 17°C
recommendation, and no whole-home savings claim. Users make their own setting changes.

## Validation and feedback

35 logic tests, 40 browser tests and 13 companion-template tests pass, alongside
type checking and linting. Browser checks include 320–768px widths, 248–504px heights,
both themes, fixed core geometry, keyboard operation and reduced motion. Real HA
sensor display and Sections layout have also been checked; simulated data covers the
winter and defrost cases. See [validation scope](https://github.com/raunosr/vallox-iv-card/blob/v2.0.0-beta.1/docs/BETA-VALIDATION.md).

Report issues with your HA/browser versions, card dimensions, relevant anonymized
configuration and a screenshot. To return to stable, redownload **v1.0.0** in HACS,
restore the saved card YAML and reload the frontend.
