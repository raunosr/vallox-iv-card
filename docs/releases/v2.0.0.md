# Vallox IV Card 2.0.0

A redesigned Vallox dashboard for Home Assistant: clearer airflow and core operation,
integrated profile controls and measured electricity in one responsive card.
**2.0.0 is a stable release, available through the normal HACS update channel.**

## What's new since 1.0

- A responsive design for Sections and masonry, with light/dark theme support and a
  compact view. The card adapts to its assigned width and height.
- A larger, stationary core with distinct heat-recovery, bypass, cool-recovery and
  defrost states, stronger flow colours, moving segments and clear arrowheads.
  Frost and droplets illustrate defrost; they are not a measurement of ice or progress.
- CO₂ and humidity stay beside extract air. The core-outlet temperature and heater
  status stay beside supply air. A labelled fan icon identifies the fan percentage.
- Home, Away and Boost buttons inside the card; optional Fireplace, Extra and Auto
  appear only when enabled in the configuration and supported by the selected unit.
- Open the configured entity's history directly from a temperature, efficiency
  number or heater symbol. Touch and keyboard activation are supported.
- Measured power, daily/24-hour energy, seven-day history and a shared timeline.
  Missing meters and insufficient history suppress consumption conclusions.
- Explainable local suggestions that account for the heating system and measured
  energy. Suggestions never change temperature or defrost settings.
- Finnish/English labels, visual configuration, visible keyboard focus, reduced
  motion and 44-pixel touch targets. A reading of 1% remains 1%; an unknown heater
  state is not displayed as off.

## Update through HACS

Open **Vallox IV Card** in HACS and update to **v2.0.0**. If necessary, use
**⋮ → Update information**, or select **Redownload → Need a different version? → v2.0.0**.
Reload the frontend, including kiosk/tablet sessions. No prerelease opt-in is required.

The attached **vallox-iv-card.js** is the complete card. The HACS resource is
`/hacsfiles/vallox-iv-card/vallox-iv-card.js`. A separately registered `/local/` copy or
isolated preview does not update with HACS; use one production resource.

## Migration

Users of 2.0 betas can keep their configuration. For 1.0 users, existing entity
bindings and `custom:vallox-iv-card` remain supported; add `fan_entity` for integrated
controls. Old absolute label positions do not carry over to the redesigned layout.
Use the pre-heater sensor for `supply_cell_temp` and set the meaning/scale of any
explicit efficiency sensor. Save existing card YAML before replacing a 1.0 layout.

## Validation and optional companions

This release promotes the functionality of beta 4. Type checking, linting, production
build verification, 35 logic tests, 50 browser tests and 13 companion-template tests
cover the card and its supplied examples. Real HA checks include sensor readings,
Sections layouts and the efficiency/heater history dialogs.

The optional seasonal and custom profile-timer blueprints remain **experimental**.
They are not installed or enabled by a HACS card update and still need real-device
timer/restart validation. Winter energy findings also need broader testing with
working meters and actual defrost history. The card works independently of these
companions and never applies suggestions automatically.
